A **Central Malvada** é uma aplicação web desenvolvida para ser o fã-clube oficial da banda brasileira de hard/heavy rock Malvada. O projeto foi construído com foco em uma UI/UX de alto padrão, adotando uma estética editorial brutalista, imersiva e fotográfica, inspirada em grandes portais de bandas de heavy metal internacionais.

## 🤘 Sobre o Projeto e Motivação

Este projeto nasceu de uma paixão genuína pelo som autoral e pela força do rock feminino no Brasil. Acompanho a banda desde 2024, mais precisamente desde o dia **31 de agosto de 2024**, quando a Malvada veio tocar aqui em Mogi das Cruzes, no Buxixo. 

Aquele show contou com a formação pesada e definitiva que explodiu no palco: **Bruna Tsuruda** na guitarra, **Rafaela Reoli** no baixo, **Juliana Salgado** na bateria e **Indira Castillo** nos vocais. A energia daquela noite foi o estopim para a criação deste espaço dedicado a documentar a história, a discografia e os próximos passos da banda (como a Eurotour e os shows de despedida desta formação no final de 2026).

## 🛠️ Tecnologias Utilizadas

O site foi arquitetado para garantir alta performance e um design system modular:
- **React + Vite:** Para uma renderização rápida e transição fluida entre as seções (Single Page Application).
- **Tailwind CSS:** Utilizado para criar a estética brutalista, garantindo o *dark mode* absoluto (#0D0D0D), texturas industriais, tipografia de impacto (Oswald / Bebas Neue) e responsividade impecável.
- **Lucide React:** Ícones minimalistas para navegação e UI.

## ✨ Funcionalidades e Estrutura

- **Hero Section:** Abertura fotográfica em 100vh com tipografia em caixa alta e visualização de impacto.
- **História (Eras):** Linha do tempo desde a fundação remota em 2020 até a internacionalização e shows em grandes festivais (Rock in Rio, Bangers Open Air).
- **Membros:** Grid editorial em escala de cinza com a biografia individual das integrantes.
- **Discografia:** Layout de três colunas detalhando álbuns, fichas técnicas completas e placeholders para integração com o player do Spotify.
- **Tour Dates:** Agenda de shows agressiva e limpa, destacando os eventos históricos e as datas de despedida da formação atual.

## 🚀 Como rodar o projeto localmente

Para clonar e executar este projeto na sua máquina, você precisará do Git e do Node.js instalados. No terminal da sua máquina, digite os comandos na seguinte ordem:

1. Clone este repositório:
git clone https://github.com/alianamoraes/central-malvada.git

2. Acesse a pasta do projeto no terminal:
cd central-malvada

3. Instale as dependências:
npm install

4. Execute a aplicação em modo de desenvolvimento:
npm run dev
